# ResNet18 Image Classification using PyTorch

## Project Overview
This project implements the ResNet18 deep learning architecture using PyTorch for handwritten digit classification on the MNIST dataset.

The objective is to understand how a Convolutional Neural Network (CNN) architecture can be used for image classification.

## Technologies Used
- Python
- PyTorch
- Torchvision
- Google Colab
- MNIST Dataset

## Model Architecture
- ResNet18
- Convolutional Neural Network (CNN)
- Deep Learning

## Dataset
The project uses the MNIST dataset, which contains grayscale images of handwritten digits from 0 to 9.

## Project Notebook
The complete implementation, including model development, training, and evaluation, is available in:

`ResNet18_MNIST_PyTorch (1).ipynb`
